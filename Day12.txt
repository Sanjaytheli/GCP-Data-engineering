select: whenever you want to fetch particular columns from dataframe then we can use select transformations

filter: as per the requirement if you want to filter our particular records based on conditions then we can use filter transformations

***************************************************************************
customer_lo_df=spark.read.format("json").load("/sourcehdfs/customer_lo.json")
select_df=customer_lo_df.select("customer_id","cust_name","grade")
filter_df=select_df.filter(select_df.grade==200)
filter_df.write.format("json").mode("overwrite").save("/sourcehdfs/target/")

Req: Read data from customer_lo.json file, after that for every record on top of grade I want to increase value as +100 by adding new column called as grade_new, ==> then fetch customer_id, customer_name, grade_new columns into my target file 

A1:

customer_lo_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_lo.json")
withcolumn_df=customer_lo_df.withColumn("grade_new",col("grade")+100)
withcolumn_df.show()
select_df=withcolumn_df.select("customer_id","cust_name","grade_new")
select_df.show()
select_df.write.format("json").mode("overwrite").save("gs://cdebatch5758sparkusecase/target1/")


withColumn(): with in dataframe if you want to change the data or if you want to add a new column as per requirement then we can use this transformation.
syntax: withColumn(colname,expression)
withColumn("grade_new",col("grade")+100)

***************************************************************************
A2:

customer_lo_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_lo.json")
withcolumn_df=customer_lo_df.withColumn("grade_new",col("grade")+100).select("customer_id","cust_name","grade_new")
withcolumn_df.show()
withcolumn_df.write.format("json").mode("overwrite").save("gs://cdebatch5758sparkusecase/target1/")

Req: I want to read data from customer_lo.json file, then I want to replace grade column with grade_new column. Then write results into my target file.


==> I want to replace grade column with grade_new column ==> rename grade column as grade_new 


A1:
---
customer_lo_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_lo.json")

==> from the datafram to pick few columns we are using select transformation, instead of this in spark we can use one more transformation drop().

drop(): from a dataframe whenever you want to skip particular columns then we can use drop() transformation

A2:
----
customer_lo_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_lo.json")
withColumn_df=customer_lo_df.withColumn("grade_new",col("grade"))
drop_df=withColumn_df.drop("grade")
drop_df.show()

withColumnRenamed(): whenever you want to rename column names in your dataframe then we can use this transformation
syntax: withColumnRenamed(oldcolumn,newcolumn)

A3:
----
customer_lo_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_lo.json")
withColumnRenamed_df=customer_lo_df.withColumnRenamed("grade","grade_new")
withColumnRenamed_df.show()
