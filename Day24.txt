Airflow Architecture:
---------------------

What all are the components which are available in airflow:

1. DAG:
		- In airflow to do any kind of activities first step we need to crate a DAG (Direct acyclic graph)
		- with in DAG we are going to define our tasks and task definitions and task dependencies and task schedule
		- while creation of the dag we are going to create a python script file (.py)
		- we need to save all these dag files into "dags folder" [this folder will create into a bucket, this bucket and folder will create automatically while creation of composer environment]
		
2. Scheduler:
		with in dag we are defining dependencies/schedules by depending on our requirement ==> scheduler component will take care of all tasks execution based on schedules which we defined in our dag file.
		
3. worker nodes: [virtual machines]
		whatever tasks you defined with in dag file those tasks are going to trigger on top of these worker node [python script]
		
4. Executor:
		to execute all your tasks based on dependencies and based on schedules it will use Executor component.
		
5. WebUI: (web user interface)
		By using this component we can able to see what is the status of each and every dag / monitor how many dags are running / monitor how many dags are succeeded and how many dags are failed and how many dags are in progress / we can able to see log information of every dag 
		
6. webServer: By usig this webserver component only above WebUI will work

7. Metadata Database: In this database it will store our task name, schedules information , dag details , data status details..etc

metadata ==> data about the data 
Metadata Database ==> data about the dags (task, dependencies, schedule, status, execution details..etc)
