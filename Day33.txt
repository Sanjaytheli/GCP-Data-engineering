Approach3: Cloud sdk shell (create database,create table,insert data,load data from the file)

1. create a database: bq mk -d dbname
		bq mk -d samplesdk
		bq query --use_legacy_sql=false "create schema samplesdk1"
2. to list your databases: bq ls
3. to list your tables: bq ls databasename
		bq ls cdebatch581
4. to create table: 

bq mk -t samplesdk.emp eid:integer,ename:string
bq query --use_legacy_sql=false "create table samplesdk.emp2 (eid integer,ename string)"

5. to see structure of our table: bq show --schema samplesdk.emp
6. To load the data into your table:
		bq load --skip_leading_rows=1 --source_format=CSV samplesdk.emp gs://cdebatch58bigquery/employee_1.csv
7. TO create and load the data from the file directly:

	bq load --autodetect --source_format=CSV samplesdk.emp1 gs://cdebatch58bigquery/employee_1.csv
	
	bq ls samplesdk
	bq show --schema samplesdk.emp1
8. TO see the data from the table: [To run the queries:]
		bq query --use_legacy_sql=false "select * from samplesdk.emp1"
		
		note: bq ==> bigquery ==> bq is kind of utility which is availablle on cloud sdk shell

Approach4:  [json schema approach]
---------

==> keep all the column names and datatypes into a json file ==> by using this json file we can create our table

bq mk -t --schema jsonfilepath databasename.tablename

bq mk -t --schema C:\Education\QT-GCP\BQ\Files\employee_schema.json samplesdk.employee5

data loading operation:
------------------------
bq load --skip_leading_rows=1 --source_format=CSV samplesdk.employee5 gs://cdebatch58bigquery/employee_1.csv

Adv: after 6 months you can verify your table structure by using above json file
