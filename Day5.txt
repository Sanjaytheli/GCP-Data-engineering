GCP Console:
------------

Done - 0. I want to see list of the buckets
Done - 1. I want to create a bucket 
Done - 2. I want to upload the files 
Done - 3. I want to upload a folder into my bucket 
Done - 4. I want to create a new folder into my bucket 
Done - 5. I want to copy the files from one bucket to other bucket 
Done - 6. I want to delete the files from the bucket 
Done - 7. I want to delete my complete bucket 


step1: open GCP console  [verify our mail id and project]
https://console.cloud.google.com
step2: go to gcs service 
	option1: Navigation menu 
	option2: search bar
step3: go to buckets from left side panel ==> click on create ==> 



Cloud SDK Shell:
-----------------
step1: start ==> cloud sdk ==> click on google cloud sdk shell application
step2: verify your account and project ==> gcloud config list

Note: from cloud sdk shell if you want to do any activities on google cloud storage service we need to use "gsutil" utility

Note: to avoid confusions while doing practice please connect to same project in both sdk and also console

Done - 0. I want to see list of the buckets: gsutil ls 
									: gsutil ls gs://cdebatch58srinivas0701/
									: gsutil ls gs://cdebatch58srinivas0701/Batch58/
Done - 1. I want to create a bucket : gsutil mb bucketname
Note: in cloud sdk shell wherever you want to give your bucket name we need to give prefix as gs://
gsutil mb gs://cdebatch58srinivassdk


Done - 2. I want to upload the files [copy the file]: gsutil cp sourcepath targetpath
gsutil cp C:\Education\QT-GCP\1_Batches\Batch58\202606290830-ClassNotes.txt gs://cdebatch58srinivassdk
gsutil cp C:\Education\QT-GCP\1_Batches\Batch58\202606290830-ClassNotes.txt gs://cdebatch58srinivassdk/xx.txt
gsutil cp C:\Education\QT-GCP\1_Batches\Batch58\202606290830-ClassNotes.txt gs://cdebatch58srinivassdk/sample/


Done - 3. I want to upload a folder into my bucket :
gsutil cp -r C:\Education\QT-GCP\1_Batches\Batch58\ gs://cdebatch58srinivassdk

-r ==> recursive 

4. I want to create a new folder into my bucket 
Note: there is no specific command in sdk shell to create the folder

Done - 5. I want to copy the files from one bucket to other bucket :
gsutil cp gs://cdebatch58srinivassdk/202606290830-ClassNotes.txt gs://cdebatch58srinivas0702/srinivas.txt


Done - 6. I want to delete the files from the bucket 
gsutil rm filename
7. I want to delete my complete bucket
