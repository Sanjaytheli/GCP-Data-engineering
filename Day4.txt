Google Cloud Storage: [GCS]

GCS ==> by using this service we can able to store files/folders/objects 

==> Google cloud storage is a "fully managed object storage" service provided by Google cloud platform. By using this service we can upload or retrieve any amounts of data at any point of time simply over the internet.

fully managed: while using GCS service as a user no need to configure any infra related things, directly open GCS service and directly you can upload any amounts of data as per requirement. In backend google will take care of all required infra configurations.

==> if you want to create a bucket on GCS service we need to take care of below things

a) bucket name: your bucket name should be unique (across the globe)

b) storage classes: based on frequency of accessing the data in bucket we can define below storage classes 
	Standard storage: if you want to access your files on daily basis [More money]
	Nearline storage: if you want to access your files on monthly basis
	Coldline storage: if you want to access your files on quarterly basis
	Archive storage: if you want to access your files on yearly basis [Less Money]
