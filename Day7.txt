VM ==> Linux ==> run our unix commands 

sample@cdebatch:~$ [unix prompt]
>>> [Python prompt]

1. I want to see list of the files and folders in VM: ls
2. I want to create a folder: mkdir foldername
		mkdir srinivas
3. in which folder I am working: pwd
4. if you want to switch from one folder to other folder: cd foldername		
		cd srinivas
5. I want to come back to my previous folder:
		option1: cd /home/sample
		option2: cd ..
6. How to create a file: cat > filename
		cat > sample.txt
		enter your content 
		ctrl+d
7. I want to see the content of the file: cat filename
8. I want to see all the content in reverse order: tac filename 
9. I want to see top 2 records of the file: head -n filename
		head -2 sample.txt
10. I want to see last 2 records of the file: tail -n filename
		tail -2 sample.txt
11. TO copy the file from one location to other location: cp sourcepath targetpath
		cp /home/sample/sample.txt /home/sample/srinivas/.
		cp /home/sample/sample.txt /home/sample/srinivas/yy.txt
		cp /home/sample/sample.txt /home/sample/srinivas/xyz/yy.txt [unix - error]
		
		option1: cd srinivas
			   : ls
		option2: ls /home/sample/srinivas
12. I want to delete the file yy.txt : rm filename
		rm /home/sample/srinivas/sample.txt

==> in my laptop I am having a file sample.txt ==> I want to get this file into my VM (Cloud)
		==> to take care of this kind of activities we can able to use one more third party application called as "WINSCP"
	
1. cloud sdk shell application: with out using GCP console if you want to do cloud activities then we can use this application
2. putty gen application: to generate the keys and to create the ppk file 
3. putty application: to connect with our VM 
4. winscp: to copy files from local system to our VM 

==> if you want to use winscp application 

step1: we need to download winscp application by using below url 
https://winscp.net/eng/download.php
step2: click on download winscp 6.5.6 (after few second it will download a 12MB file into your downloads folder)
step3: go to downloads folder ==> double click on .exe file ==> agree terms and condition / single user or multi user / next next next install [straight forward installation]
step4: we need to open winscp application 
start ==> winscp ==> click on winscp application

hostname: VM ipaddress
username: sample
ppk file: click on advanced ==> ssh ==> authentication ==> provide your ppk file path
