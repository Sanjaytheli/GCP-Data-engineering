Data warehousing process: [DWH]
------------------------------
Collection of the data from different sources then we are converting unorganized data into organized format for the purpose of doing analysis to take the decision.

in this DWH process what activities we need to take care ? E,T,L

1. Collection of the data or extraction of the data ==> E 
2. Converting the data or transform the data ==> T 
3. Load the data ==> L 

how we can able to perform these ETL operations ??

Option1: By using available ETL tools in the market [Informatica/datastage/abinitio/SSIS..] [ETL Developers]
	problems:
		a) for all these ETL tools we need to take license by paying huge amounts of money 
		b) these ETL tools can not able to handle very very huge amounts of data 
		c) these ETL tools can not able to handle unstructured data 
	
	To overcome all these issues Hadoop framework came into the picture 
	
Option2: By using Hadoop stack [Data Engineers]
	a) hadoop is a open source framework [free]
	b) we can able to handle huge volumes of data 
	c) we can able to handle unstructured data 
	
	to use Hadoop stack we need to create hadoop cluster 
	
	cluster ==> group of machines 
	
	to create hadoop cluster
	
	1. we need to purchase all the machines 
	2. we need to configure all the machines 
	3. we need to take care of installation of OS in all these machines
	3. we need to take care of installation of SW in all these machines
	3. we need to take care of installation of security patches in all these machines
	6. we need to establish communication between all these machines by using purchasing networking components
	7. Maintenance activities
	
	To do all above activities in manual manner it will take more amount of time and also we need to spend more amount of money and maintenance activities become very very challenging
	
	To overcome all above infra related issues "CLOUD" came into the picture.
