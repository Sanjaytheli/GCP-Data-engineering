Req: I want to read data from customer_lo.json file and also customer_ny.json files , combine all customers data from both the files then I want to filter out grade=100 customers, I want to add one additional column country_cd, then in this column wherever city='london' populate value as 'lo' and if city <> 'london' then populate values as 'xx' ==>  and then final result I want to capture into my target file.

==> in this requirement we need to implement kind of if-else logic 
if city='london' then 'lo'
else 'xx'

==> from spark side if you want to implement if-else logic we can apply "when" and "otherwise"


from pyspark.sql.functions import col,lit,when
customer_lo_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_lo.json")
customer_ny_df=spark.read.format("json").load("gs://cdebatch5758sparkusecase/source/customer_ny.json")
cust_lo_filter_df=customer_lo_df.filter(customer_lo_df.grade==100)
cust_ny_filter_df=customer_ny_df.filter(customer_ny_df.grade==100)
union_df=cust_lo_filter_df.union(cust_ny_filter_df)
withColumn_df=union_df.withColumn("country_cd",when((col("city")=="London"),lit("lo")).otherwise(lit("xx")))
withColumn_df.show()

==> in all above examples we are using our "spark transformations" to achieve our requirements, if you are using spark transformations to achieve our requirements that kind of approach we can call it as "SPARK DSL" approach. [DSL - domain specific language]

==> all above example we can handle with out using spark transformations, instead of using spark transformations we can use our "SQL queries". If you are u sing sql queries to achieve our requirements that approach we can call it "SPARK SQL" approach.

==> we need to follow below steps to follow spark sql approach 

step1: read data from the file with that create a dataframe
step2: on top of this dataframe we are going to create a temp view (temp_v)
dataframe.createOrReplaceTempView("temp_v")
step3: now by using above temp view we can frame our sql statement, after that we need to pass this sql query into spark.sql()
df=spark.sql("select * from temp_v where grade=200")
step4: df.show()
