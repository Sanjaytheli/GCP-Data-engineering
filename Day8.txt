Hadoop:

1. To store the data : [HDFS] [Hadoop Distributed File System]

==> laptop ==> folder ==> store our files [Local File system]
==> hadoop ==> HDFS [data storage going to happen in distributed manner]

2. Data processing operations: [Map Reduce(MR)]

Important characteristics of hadoop:

1. Distributed framework: whatever the workload we are getting that workload will distribute across all the nodes in the cluster in parallel manner.
2. Replication Factor: Your data on every machine will take it as backup into other machines, this kind of data we can call it as replicated data. whenever a machine is going to fail then by using other machines we can revert the data.
3. Fault Tolerance: whenever a machine is going to fail then automatically other machines will come into the picture to take care of all the responsibilities of the failed machines
4. BLock based storage: Your data is going to divide into fixed size blocks (128MB or 256MB) and distributed across the nodes in the cluster.
5. Master - Slave architecture:
		Master node (name node)
		Slave node (data nodes)

How cluster can enable to understand in which node which block of data it is stored ?

8 Node cluster ==> 
		1 node ==> master nodes
		7 node ==> slave nodes 

Master node:
	a) it will maintain all the metadata of our slave nodes (data about data ==> data about slave machines)
			1. it will maintain ipaddress of every slave machine
			2. it will maintain configurations of every slave machine 
			3. it is going to maintain health status of every slave machine 
			4. will provide guidance to slave nodes what tasks need to execute and what data need to store in which slave node
			5. master node will capture in which slave node which block of data has been stored 

Slave node: 
	a) slave nodes will save all the actual data 
	b) slave nodes will take care of actual execution activities
