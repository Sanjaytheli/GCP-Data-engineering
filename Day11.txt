Hadoop ==>
	storage (HDFS)
	processing (MR)
	
	LFS ==> HDFS (copy the files)
	
	Dataproc cluster ==> VM ==> Linux ==> Folders (LFS) ==> HDFS
	
	windows OS ==> Folders/files ==> LFS 
	Linux OS ==> Folders/Files ==> LFS 
	
	Done - step1:
	copy the files from LFS (windows) to LFS (VM-Linux folders)  [winscp]
	mkdir source
	
	Done - step2:
	Copy the files from LFS (VM-Linus folders) to HDFS (VM - Hadoop framework) [HDFS commands]
	
	1. If you want to see list of the files or folder in HDFS ==> hdfs dfs -ls /
	2. If you want to create a folder in HDFS ==> hdfs dfs -mkdir /sourcehdfs
	3. COpy the files from LFS to HDFS ==> hdfs dfs -put sourcepath targetpath
			hdfs dfs -put /home/sample/source/customer_lo.json /sourcehdfs
			hdfs dfs -put /home/sample/source/*.* /sourcehdfs

whenever you want to perform data processing operations by using spark first step is "Read data from the files"

customer_lo_df=spark.read.format("json").load("/sourcehdfs/customer_lo.json")
customer_lo_df.show()

Req: ==> From above dataframe I want to see data for particular columns ==> "SELECT" transformation

Table ==> c1,c2,c3,c4,c5 
select c1,c2 from table;

select_df=customer_lo_df.select("customer_id","cust_name","grade")
select_df.show()

==> in above example we are performing data processing operations ==> we are hiding the columns

Req: ==> From above dataframe I want to filter out grade=200 records ==> "FILTER" transformation 

filter_df=select_df.filter(select_df.grade==200)
filter_df.show()

==> in above example we are performing data processing operations ==> we are hiding the rows (Filtering the records)

==> to take care of write operations we need to write below line of the code 

dataframe.write.format("").save("")
filter_df.write.format("json").save("/sourcehdfs/target/")

How to prove my write operations is complete or not ??
Option1:
	hdfs dfs -ls /sourcehdfs/target/
Option2:
	df=spark.read.format("json").load("/sourcehdfs/target/")
	df.show()
